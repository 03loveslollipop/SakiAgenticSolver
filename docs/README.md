# Project Docs (consolidated)

This folder contains focused, non-operational documentation that is safe to keep in the repository. Procedural runbooks and any documents that reveal how to obtain or upload secrets, or step-by-step deployment instructions, have been removed from the repository and should be kept in your private runbook or secret vault.

Files:
- `DEPLOYMENT.md` — High-level deployment architecture and canonical secret / environment variable names (no operational steps)
- `AUTHENTICATION.md` — Authentication design summary and key configuration names
- `MONGODB.md` — Database configuration modes and canonical variable names

If you would like additional documentation moved into `/docs` (e.g., testing, architecture diagrams, non-sensitive runbooks), tell me which files to include and I will summarize them here as non-operational references.
